# Yousif Shasha — Engineering Portfolio

This is a simple editable portfolio website built with HTML, CSS, and JavaScript.

## How to use it
1. Open `index.html` in a browser to preview the site.
2. Edit the text in `index.html`.
3. Edit colors, fonts, spacing, and layout in `style.css`.
4. Edit animations/interactions in `script.js`.
5. Put project images inside the `images` folder.
6. Add your resume as `resume.pdf` in the main folder.

## Publishing
You can publish this for free with GitHub Pages, or upload it to another web host.

## Important
The project descriptions are placeholders based on the portfolio direction we discussed. Replace them with your real project details, measurements, results, photos, and calculations. Describe independent work as independent/personal projects and course work as academic projects.
